## Deploy on GitHub Pages
1. Create a new public repository, for example `digital-marketing-portfolio`.
2. Upload **all files and folders inside this project**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the live website URL.

The website uses only HTML, CSS and JavaScript, so no build step is required.
